4. Soft public go-live checklist

  • Redeploy latest frontend to Cloudflare Pages (civicsign-web, branch main) — sidebar + latest fixes
  • Confirm Render env: DEV_MODE=false, COOKIE_SECURE=true, STRIPE_REQUIRE_LIVE=true
  • Confirm deliberate registration policy: keep open for public OR set REGISTRATION_ENABLED=false for invite-only
  • Set REACT_APP_PRIVATE_BETA=false on next frontend build if you want zero “beta” messaging
  • Stripe Dashboard → webhook https://api.civicsign.co.uk/api/webhook/stripe includes: checkout.session.*, customer.subscription.*, invoice.payment_succeeded, invoice.payment_failed, invoice.upcoming, charge.refunded
  • One human dry-run: register → verify email → Pro trial checkout → send envelope → sign → download
  • UptimeRobot (or similar) on /api/health every 5 minutes
  • Support mailbox monitored (e.g. info@civicbot.co.uk) Mon–Fri
  • Rotate pilot / admin passwords if still seed defaults in production
  • Confirm Resend domain SPF/DKIM for noreply@civicsign.co.uk

5. Full public launch checklist

  • LinkedIn / email announcement with pricing + 30-day trial
  • Google Search Console: submit sitemap.xml
  • Spot-check solutions pages + blog on mobile
  • Refund / cancel path tested once on live Stripe (then refund test charge)
  • Incident notes: who restarts Render, who checks Stripe, who replies to users
  • Optional: Product Hunt / legal-tech lists / warm intro emails
